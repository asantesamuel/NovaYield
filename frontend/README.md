# Frontend

React + TypeScript application built with Vite. This is the initial shell only; feature pages and components are left to their own tickets.

From this directory, run `npm install`, then `npm run dev`. Use `npm run lint`, `npm run typecheck`, and `npm run build` for the configured checks. Set `VITE_API_BASE_URL` in `.env.local` to point at the FastAPI API; it defaults to `http://localhost:8000/api/v1`.
